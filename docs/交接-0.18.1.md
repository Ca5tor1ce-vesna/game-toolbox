## 纪律（踩过的坑，别再犯）

* **改之前先把要改的那段完整读出来**；锚点用**唯一上下文**；缩进从**目标行复制**。
* **改完立刻：语法检查 → 起服务实测 → 跑测试**（三步都要）。
* **Windows 上别用 `Path.write_text` 写要进版本库的文件**：文本模式按 `os.linesep` 把 `\n`
  翻成 CRLF（基准文件就这么被写成 CRLF：68813 → 72639 B，**看起来像内容改了，其实只差行尾**）。
  用 `write_bytes(...encode("utf-8"))`，或像 `make_web_oracle.py` 一样跟着原文件行尾走。
* **`print` 的字符要 GBK 编得出**：`🔄 ✅ ❌ ⚠ ✓ ✗` 一 print 就崩，而且崩在最后几行
  （包已打完、脚本报失败、`-latest` 不刷新）。用 `[OK]/[X]/[刷新]`。只 `print` 是雷区，
  文档字符串/测试名里的 emoji 不会崩（`unittest` 会转义）。
* **别拿 `dist/` 当"上游原样"的参照物** —— 那是用当前树打的包。
* **`.ps1` / `.bat` 带中文必须 UTF-8 带 BOM**（`.ps1` 更保险保持纯 ASCII）。
* **`Join-Path` 遇到以 `.` 开头的路径段会把下一个参数当 `-Credential`**：
  写 `Join-Path $dir ".asset-cache"`，别写 `Join-Path "$dir\.asset-cache"`（踩过，静默失败）。
* **网页版与 Python 是两份内核**：改 `api.py` 的口径必须同步 `web_api.js`，再跑 `check_web_port.mjs`。
* **目录整体改名可能被拒**（`WinError 5`）：用「建目标目录 + 逐项 `shutil.move`」绕。
* 自查用"**数据 → 文件**"的反向一致性核对（曾出现 23 条数据指向不存在的文件，
  而只看"还有几个远程 URL"却完全正常）。
