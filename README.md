# 游戏实用工具箱

b站：@syllo椭圆 出品的《崩坏：星穹铁道》配速工具箱。

## 能做什么

- **配速查询**：选角色、光锥、星魂和遗器，算出实际速度，以及混沌回忆、异相仲裁、虚构叙事、末日幻影各 T 数、各动数需要的速度；还差多少会直接告诉你。
- **自定义角色**：没收录的角色也能算，自己填基础速度和行迹速度。
- **自动推荐配装**：在能用的光锥和遗器里找出达成目标最省的几套，一键套用。
- **我的配装**：常用的配置存下来，下次一键读取。
- 另有阿哈时刻配速等小工具。

## 下载和使用

1. 到 [Releases](https://github.com/txh0058-blip/game-toolbox/releases) 下载最新的 `游戏工具箱-v版本号-绿色版.zip`。
2. 解压到任意文件夹（路径带中文或空格也没问题）。
3. 双击 `游戏工具箱.exe`。不用装 Python，也不用联网安装任何东西。

第一次打开时，Windows 可能提示「已保护你的电脑」，因为 exe 没有数字签名。点「更多信息」再点「仍要运行」即可。你的配装存在解压目录里的 `userdata/`，换新版本时把这个文件夹复制过去就不会丢。

更多说明见压缩包里的 `使用说明.html`，每个版本改了什么见 [修改记录](修改记录.md)。
